# Bulgaria Partner Intelligence

Market-research repository for Cosentino's retail and projects partner intelligence work in Bulgaria. It combines the underlying research evidence, the normalized dataset, and an executive web dashboard.

Market research and dashboard created by **Francisco González**.

## Open the application

Open [`BG_partner_intelligence/index_R_P.html`](BG_partner_intelligence/index_R_P.html) directly in a browser, or serve it locally:

```powershell
Set-Location .\BG_partner_intelligence
python -m http.server 8000
```

Then visit `http://localhost:8000/index_R_P.html`.

The application is static and dependency-free (no build step, no backend).

## Source-of-truth datasets

- `research/retail_sofia.json`, `research/retail_plovdiv.json`, `research/retail_varna.json`, `research/retail_burgas.json` — 93 retail actors across the 4 target cities.
- `research/projects_volume.json` — 19 actors in the >2,000 m² volume-based projects channel.
- `research/projects_tourism.json` + `research/projects_tourism_developments.json` — 13 actors and 14 named developments in the Black Sea coast / mountain resort tourism channel.
- `data/developments_volume.json` — 9 named developments hand-extracted from the volume-channel actor records.
- `BG_partner_intelligence/data.js` — the consolidated `RETAIL_DATA` (93), `PROYECTOS_DATA` (32: 19 Volume + 13 Tourism) and `DEVELOPMENTS_DATA` (23) consumed by the app, generated by `data/build_dataset.js`.

To regenerate `data.js` after editing the research JSON:

```powershell
node data/build_dataset.js
```

## Repository guide

- `prompt.md` — the research brief (in the lineage of Baku → Uzbekistan 2.0 → Russia), covering methodology, languages (Bulgarian/Russian/English), sources, and the retail + projects (volume + tourism) channel definitions.
- `research/` — raw Firecrawl research output, retained as source evidence.
- `data/` — the dataset build script and hand-curated developments file.
- `BG_partner_intelligence/` — the EN/BG/RU executive web application.

## Main application capabilities

- Executive landing page with Retail and Projects channels, trilingual from the first screen (English / Български / Русский).
- Positioning map, account list, priority shortlist, coverage, and competitive landscape views.
- Projects channel splits into two sub-channels — Volume (>2,000 m²) and Tourism resort (Black Sea coast / mountain) — filterable independently.
- Dedicated project-developments view (23 named developments) with status and timing evidence.
- Right-hand evidence drawer, EN/BG/RU language toggle, and filtered CSV export.
- Transparent, in-app priority scoring model; commercial recommendations are clearly separated from verified evidence.

## Data handling

The repository preserves source evidence. Missing information in the application is marked as not evidenced or not determinable; commercial interpretations (priority tiers, entry-angle recommendations) are computed transparently in the app and must not be read as verified facts — validate with the local team before acting on them.
